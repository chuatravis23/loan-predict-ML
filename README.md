# 💰 Loan Approval Prediction Dashboard

A comprehensive, interactive web application built with **Streamlit**, **Scikit-Learn**, and **Plotly** to predict loan eligibility and evaluate machine learning model performances.

---

## 🚀 Features

* **📊 Dataset Overview:** Inspect raw data samples, view class distribution charts, and analyze statistical data summaries.
* **🤖 Model Testing & Metrics:** Compare multiple classification algorithms (**Logistic Regression**, **Random Forest**, and **Support Vector Machine**) using accuracy, precision, recall, F1-score, MSE, and RMSE.
* **📈 Visualizations:** Explore correlation matrices and dynamic performance graphs.
* **🔮 Interactive Loan Prediction:** Input custom applicant details through an intuitive form, validate inputs based on domain rules, get real-time approvals/rejections via a trained **Random Forest** model, and track prediction histories with CSV export functionality.

---

## 🛠️ Tech Stack & Libraries

* **Frontend / UI:** [Streamlit](https://streamlit.io/)
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (Logistic Regression, Random Forest, SVC, StandardScaler, evaluation metrics)
* **Data Visualization:** Plotly, Seaborn, Matplotlib
* **Model Persistence:** Joblib
